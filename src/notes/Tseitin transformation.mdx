## Why bother?

Distributing OR over AND can make a formula balloon. For example, an OR of $n$ separate two-variable ANDs produces $2^n$ clauses under direct distribution. With Tseitin, each gate gets a fresh variable and a fixed number of short clauses. For a formula built from these unary and binary gates, the encoding grows linearly with the number of gates.

We’ve traded a few more variables for a manageable number of clauses. That’s the trick I want to remember: **name the pieces, constrain the names, require the output.**
